# Portfolio Website (2024)

My first portfolio site, built with plain HTML, CSS and JavaScript. A simple starter template with About, Projects, Skills and Contact sections.

**Live demo:** https://umar8092.github.io/portfolio-website-2024/

## Use it

Download or clone the repo and open `index.html` in a browser. No build step or dependencies.

```
git clone https://github.com/umar8092/portfolio-website-2024.git
```
